#### 过拟合：把运气当成规律

把窗口从 20 调到 17、再调到 23，总能试出一个在历史上更好看的数字，但这往往只是凑巧，换一段时间就不灵了。就像做了很多遍同一张卷子后考了高分，并不代表真的学会了。建议：

- 窗口优先用有实际含义的整数：5（一周）、20（一个月）、60（一个季度）、120（半年）、250（一年）。
- 把评价区间分成两段：在前一段做研究，**最后只用后一段验证一次**。
- 参数稍微一改结论就反过来的因子，不要采用。

#### 单位不统一与极端值

把“涨幅”（零点几）和“成交量”（几十万）直接相加毫无意义，大数字会完全盖过小数字。合并之前先用 `cs_rank` 或 `cs_zscore` 换算到同一把尺子上；对市值、成交额这类大小相差悬殊的数据，先取 `log`。

#### 缺失值与除以零

- 没有数据的位置用 NaN 表示。NaN 参与加减乘除后结果还是 NaN，会让能算出分数的股票变少（覆盖度下降）。
- 除数为 0 的结果是 NaN。分母可能为 0 时，加一个很小的数，例如 `(high - low + 0.001)`。
- `log` 遇到小于等于 0 的数、`sqrt` 遇到负数，结果也是 NaN。
- 时序算子在数据最开始的 n−1 天没有足够的历史可看，结果是 NaN，这是正常现象，不是报错。

#### 因子太相似（同质化）

20 日动量和 60 日动量打出来的分数往往非常接近。组合里放两个相关性高于 0.7 的因子，几乎起不到分散的作用。「因子组合」的评价结果里会给出相关性表格，帮你发现这种情况。

#### 交易成本

短周期的反转类因子 IC 往往很高，但每天都要大量换股，费用很可能把收益全部吃掉。用 `ts_mean` 或 `ts_decay_linear` 把分数平滑一下，可以明显减少换股：

```
alpha = ts_decay_linear(cs_rank(pct_chg), 10)
```
