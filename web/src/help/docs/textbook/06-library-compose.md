单因子在不同区间上经常翻脸。把机制不同的因子合成，失效期往往错开。合成之前，先用因子库把候选筛干净。

## 1. 因子库

[因子库](#/library) 同时存放内置因子和你保存的因子。内置公式的权威清单在[内置因子](#builtins)，和你是否删过库里的副本无关。

| 操作 | 说明 |
| --- | --- |
| 评价选中 / 评价全部 | 写出 RankIC、ICIR、多头超额；未勾选 = 全部 |
| 表头排序 | RankIC、ICIR、超额、更新时间 |
| 筛选 | 名称、表达式、分类、来源（内置 / 自建 / AI / 组合） |
| 详情 | 公式、指标、图；可复制、编辑、删除 |
| 导入 / 导出 | JSON 备份与交换 |

建议第一次：评价全部 → 按 RankIC 排序 → 打开头部几条对照公式，看是不是同一类动量换了窗口。

改表达式会使旧指标作废（显示为 —），需要重新评价。公式引用了当前面板没有的字段时，标记为不可用，不影响其余因子。

## 2. 组合在算什么

引擎不会「凭感觉」混合。合成步骤是固定的：

1. 每个成分的中间变量加前缀隔离，避免两个因子都叫 `mom20` 时互相覆盖。
2. 每个成分的终值先做当日 `cs_zscore`，否则市值这种数量级会压倒收益率。
3. 按权重和方向线性相加：`alpha = w1*z1 + w2*z2 + …`
4. 任一成分当日是 NaN，该股组合值也是 NaN（宁缺毋滥）。

## 3. 在页面上搭建

1. 打开[因子组合](#/compose)，填写名称。
2. 加入至少 2 个因子。AI 推荐只从库中已有因子里挑，不会写新公式。
3. 检查方向：成分自己的 IC 为负时，切到「反向」。
4. 权重：不确定就等权。自定义时数值大为权重大。
5. 运行评价，满意后保存。

表里每一行的 IC / 收益是**该成分自己**最近一次评价，不是组合结果。组合指标必须点「运行评价」。展开「合成表达式」可以核对最终 DSL。

## 4. 相关性：同质化用数字判断

评价结果下方的成分相关矩阵，取值 [−1, 1]，衡量两个因子分数有多像。看分数，不要看名字。

| 相关 | 怎么处理 |
| --- | --- |
| > 0.7 | 几乎同一信息，留一个 |
| 0.4～0.7 | 部分重叠，加进去作用有限 |
| < 0.4 | 比较互补，适合共存 |

20 日动量和 60 日动量通常落在第一档。动量 + 低波动、量价 + 估值，更容易进第三档。
