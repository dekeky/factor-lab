| 编辑器里的报错 | 意思 | 怎么改 |
| --- | --- | --- |
| `未知的字段或变量 "xxx"` | 用到了一个平台不认识的名字。 | 检查是否拼错（对照“基础指标”）；如果是自己定义的变量，确认定义它的那一行写在使用它之前。 |
| `未知算子 "xxx"` | 函数名写错了，或者平台没有这个函数。 | 对照“算子参考”。常见笔误：把 `ts_mean` 写成 `ts_avg`、把 `cs_rank` 写成 `rank`、把 `ts_std_dev` 写成 `ts_std`。 |
| `算子 xxx 期望 N 个参数，实际 M 个` | 括号里填的内容个数不对。 | 最常见的是漏了窗口：`ts_mean(close)` 应写成 `ts_mean(close, 20)`。每个算子需要几个参数见“算子参考”。 |
| `xxx 第 N 个参数必须是常数（如窗口长度 20）` | 窗口位置只能直接写数字。 | 不能写成变量或算式，例如 `ts_mean(close, n)` 或 `ts_mean(close, 10 + 10)` 都不行，直接写 20。 |
| `xxx 第 N 个参数必须是 1~512 的整数` | 窗口数字超出了允许范围。 | 窗口不能是 0、负数、小数，也不能超过 512。 |
| `变量名 "xxx" 与字段重名，请换名` | 自己起的变量名和平台字段撞名了。 | 例如不能写 `close = …`，换一个名字，如 `my_close = …`。 |
| `非法字符 "…"` | 出现了公式里不允许的符号。 | 多半是中文输入法下的全角符号：（ ） ， ； ＝ 等，切换到英文输入法重新输入。变量名也只能用英文字母、数字和下划线，不能用中文。这类报错引号里的字符常显示成乱码（如 `"ï"` `"¼"`），并且会连续出现好几条，按行号去找中文符号即可。 |
| `期望 xxx，实际是 xxx ／ 意外的记号` | 公式的“语法”不完整。 | 检查括号是否成对、两个值之间是否漏了运算符、末尾是否多了逗号。报错里的行号能帮你定位。 |
| `空表达式：至少需要一行因子定义` | 编辑器里没有任何有效公式。 | 只有注释（`#` 开头）或空行不算，至少写一行公式。 |
| `表达式嵌套过深` | 一行里括号套了太多层。 | 用变量把公式拆成几行，既能通过校验，也更容易看懂。 |
