#### 它是什么

评价报告告诉你“因子有没有预测能力”，实盘模拟则更进一步：给你一笔**虚拟资金**，严格按真实的交易规则每天选股、买卖、记账，让你看到账户的钱到底怎么变化。平台不连接任何券商账户，**不会产生真实交易**。

#### 新建一个模拟盘

在「实盘模拟」点 **新建模拟盘**，填写下面几项后点 **开始模拟**：

| 参数 | 含义 | 新手建议 |
| --- | --- | --- |
| **信号来源** | 用哪个因子或组合来给股票打分 | 选一个评价结果不错、且多头(净) 能跑赢全市场的 |
| **Top N** | 每天持有分数最高的多少只股票 | 默认 10。越少越集中，涨跌起伏也越大 |
| **调仓阈值** | 换股的“缓冲带”，详见下方说明 | 先用 0 体验，再试 5～10 对比换股次数 |
| **本金** | 虚拟资金的数额 | 默认 100 万。金额太小可能买不起某些高价股的 100 股 |
| **单边成本** | 每次买或卖的费用比例。注意这里填的是小数：`0.003` 表示 0.3% | 保持默认 |
| **起始日** | 从哪一天开始模拟；留空则从平台已有行情的第一天开始 | 留空 |

#### 每个交易日发生了什么

1. **打分**：收盘后，用冻结的因子公式给所有股票打分并排名。停牌、涨停或跌停的股票当天不参与选股。
2. **选股**：排名前 N 的股票成为目标持仓。
3. **成交**：**下一个交易日开盘**时买入新入选的、卖出被淘汰的（T+1）。资金平均分配给每只股票，买入数量取 100 股的整数倍。
4. **记账**：按当天收盘价计算账户总资产，画到净值曲线上。

#### 调仓阈值举例

假设 Top N = 10、调仓阈值 = 5：新买入时只从排名前 10 的股票里挑；但已经持有的股票，只要排名还在前 15（10 + 5）以内就继续持有，跌出前 15 才卖掉。

这样可以避免一只股票今天第 10 名、明天第 11 名、后天又回到第 10 名时来回买卖，白白浪费手续费。阈值越大换股越少、费用越低，但持仓可能不是当天最新的前 10 名。

#### 看懂模拟盘页面

- **四个数字**：净值（现在账户总共值多少钱）、累计盈利（比本金多了或少了多少）、最大回撤（历史上从高点最多跌过多少）、现金（还没买成股票的钱）。
- **净值曲线**：红色实线是账户总资产，灰色虚线是本金。红色三角表示当天有新股票买入，绿色三角表示有股票被卖出；点击曲线上的任意一天可以查看当日明细。
- **每日选股**：用右上角的下拉框切换日期，可以看到当天的入选名单、被剔除的股票、持仓和成交记录。点击股票名称可以打开它的日 K 线图。

| 状态标签 | 含义 |
| --- | --- |
| 入选 | 进入了当天的目标持仓名单 |
| 成交 | 这笔买入或卖出已经完成 |
| 停牌 / 涨停 / 跌停 | 因为无法交易，当天被跳过 |
| 无行情 / 不可交易 | 当天缺少价格数据，无法成交 |
| 待成交 | 已经选出股票，等下一个交易日的行情到了才成交 |

#### 需要知道的三件事

- **公式是冻结的**：模拟盘在创建那一刻保存了当时的公式，之后你再修改因子库里的因子，不会影响已有的模拟盘；已经发生的买卖记录也不会被改写。
- **想推进到新的日期**：平台的行情在服务启动时下载。行情更新后（重启服务），点 **同步新行情**，模拟盘就会补上新的交易日。
- **分清“回放”和“真实跟踪”**：新建时，模拟盘会从起始日一路按历史行情推演到最新一天，这一段本质上仍然是历史回测。只有创建之后新增的交易日，才是因子没“见过”的、最有说服力的表现。
