1. **提出想法**：例如“短期涨太多的股票会回调”。
2. **写成公式**：在「因子工厂」把想法翻译成公式，编辑器会自动检查写法是否正确。不会写可以让右侧的 AI 助手帮忙。
3. **评价**：点「▶ 运行评价」，查看 RankIC、分层收益、成本等结果（见教程[读懂评价报告](#guide-read-report)）。
4. **检验是否稳定**：换一个评价区间、换一个持有期或股票池再评价，看结论是否依然成立。
5. **保存与组合**：保存到「因子库」；在「因子组合」把几个互补的因子合在一起，并检查它们是否过于相似。
6. **模拟验证**：在「实盘模拟」用虚拟资金逐日按因子选股，观察一段时间的真实表现。

不必每一步都一次做到完美。常见的节奏是：快速写出 5～10 个变体 → 用评价报告淘汰掉大部分 → 只对剩下的少数几个认真做稳定性检验。

> [!NOTE]
> 大多数想法评价出来都是“没用”的，这很正常。淘汰得快，本身就是研究效率。
