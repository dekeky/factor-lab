评价回答「因子有没有截面预测力」。模拟盘回答「按 A 股可交易约束选股、下单、记账，账户净值如何走」。资金是虚拟账户，不报单。

## 1. 和评价差在哪里

| | 评价 | 模拟盘 |
| --- | --- | --- |
| 成交假设 | t+1 收盘，全市场等权分组 | t+1 **开盘**，只持有 Top N |
| 价格 | 后复权 `close` 算收益 | 前复权开盘成交；无该列时退回 `open`。持仓按当日收盘计价 |
| 约束 | 无 | T+1、停牌、涨跌停、100 股整手 |
| 费用 | 用换手粗估年化成本；多头(净) 按日扣 | 每笔成交扣单边成本 |

评价好看、模拟盘难看，常见原因是：开盘买不到涨停、整手取整买不足、换手在真实成交里被放大。

## 2. 参数

| 参数 | 含义 | 建议 |
| --- | --- | --- |
| 信号来源 | 打分用的因子或组合 | 评价里多头(净) 已经高于全市场 |
| Top N | 目标持仓只数 | 默认 10；越小越集中 |
| 调仓阈值 | 已持仓跌出 Top N + 阈值 才卖 | 默认 20；0 表示刚跌出 Top N 就换 |
| 本金 | 虚拟资金 | 默认 100 万；过小可能买不足 1 手 |
| 单边成本 | 买或卖一次的费率，小数 | `0.003` = 0.3% |
| 起始日 | 模拟起点 | 默认 = 当前交易日（面板最后一根） |

## 3. 每个交易日做什么

1. **打分**：用创建时冻结的公式。停牌、开盘涨停、开盘跌停不参与当日新开仓。
2. **目标持仓**：排名前 N（受阈值缓冲）。已持仓：停牌或开盘跌停卖不掉，继续拿着；开盘涨停可以卖、不能买。
3. **成交**：下一交易日开盘买入新入选、卖出被淘汰。资金等权，数量向下取整到 100 股。
4. **记账**：按收盘价更新总资产。账本只追加，不回写已经发生的交易日。

例：Top N = 10、阈值 = 5。新开仓只从前 10 名选；已持仓只要仍在前 15 名就留。阈值越大换手越低，持仓也越偏离当天的前 N。

## 4. 页面上的标签

净值、累计盈亏、最大回撤、现金。净值曲线上的三角是买卖；点某一天看出入选、剔除、持仓和成交。

| 标签 | 含义 |
| --- | --- |
| 入选 | 进入当日目标持仓 |
| 成交 | 买卖已完成 |
| 停牌 / 涨停 / 跌停 | 当日无法按规则交易，跳过 |
| 无行情 / 不可交易 | 缺价格 |
| 待成交 | 已选出，等待下一交易日行情 |

## 5. 三条容易踩的规则

1. **公式冻结。** 创建瞬间保存表达式。之后改库里的因子，不会改写已有模拟盘和历史成交。要用新公式就新建一个模拟盘。
2. **行情按启动时加载。** 更新数据后重启服务，再点「同步新行情」补交易日。
3. **回放不是样本外。** 创建时从起始日推到最新一日，仍是历史回测。创建之后新出现的交易日，才是这条因子当时没见过的区间。
