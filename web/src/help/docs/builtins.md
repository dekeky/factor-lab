平台随版本发布 {{builtin_count}} 条内置表达式，启动时写入因子库（来源 = 内置）。本清单以引擎注册表为准，不受你在库里增删副本的影响。

它们是可复现的研究模板，不是推荐组合，不构成投资建议。公式所需字段在当前面板里缺失时，该条显示不可用。

## 1. 收录范围

| 类别 | 来源 | 范围 |
| --- | --- | --- |
| Alpha101 | Kakushadze (2016) | 现有算子能直接表达的子集，不是 101 条全集 |
| Alpha158 | 微软 Qlib（MIT） | K 线形态、乖离、波动，语义自实现 |
| 风格因子 | 教科书口径 | 动量、反转、波动、量价、估值、质量、规模 |

原论文 / Qlib 字段名在本平台中的替换：

| 常见写法 | 本平台 |
| --- | --- |
| `returns` | `pct_chg` |
| `volume` | `vol` |
| `vwap` | `amount / vol` |
| `adv20` | `ts_mean(vol, 20)` |

## 2. 怎么用

1. 展开一行，复制表达式到[因子工厂](#/factory)运行，或只改窗口再评价。
2. 库中删错了内置条目：从此处复制，再到因子库新建。
3. 改内置因子时先复制再改，保留原式便于对照。

需要 `roe` / `pe_ttm` / `pb` 的条目在估值数据缺失时显示不可用。风格类（动量、反转、低波动）只依赖 K 线，Tushare 日行情就绪即可跑。

## 3. 读公式时注意方向

平台约定分数越高越买。不少 Alpha101 原式带 `-1`，表示原作者认为该信号是反转。评价后 RankIC 为负，再乘 `-1` 即可。不要因为名字叫 momentum 就默认方向对。
