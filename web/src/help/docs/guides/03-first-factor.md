因子公式的写法和 Excel 公式很像：用**字段名**（平台提供的数据，如 `close`）、**加减乘除**和**函数**（平台叫“算子”，如 `ts_mean`）拼出来。下面每一步的公式都可以直接粘贴到「因子工厂」的编辑器里试。

#### 第 1 步：引用字段

只写一个字段名，就已经是一个合法的因子。例如直接用收盘价当分数（股价越高分数越高，没什么实际意义，仅用于理解）：

```
close
```

#### 第 2 步：做加减乘除

字段之间可以直接运算。“收盘价比开盘价涨了多少”：

```
(close - open) / open
```

例如某只股票开盘 10 元、收盘 10.5 元，结果是 (10.5 − 10) ÷ 10 = 0.05，也就是当天日内涨了 5%。

#### 第 3 步：往回看一段时间

`ts_delay(x, n)` 表示“n 个交易日之前的 x”。今天的收盘价除以 20 个交易日前的收盘价再减 1，就是这 20 天的涨幅（常叫“20 日动量”）：

```
alpha = close / ts_delay(close, 20) - 1
```

例如今天收盘 12 元、20 个交易日前收盘 10 元，结果是 12 ÷ 10 − 1 = 0.2，即涨了 20%。括号里的 20 叫**窗口**，必须直接写 1～512 之间的整数。

#### 第 4 步：在所有股票之间排名

不同股票的涨幅差别可能非常大，个别暴涨的股票会“带偏”结果。`cs_rank` 会把当天所有股票从低到高排队，换算成 0～1 的分数，这是业内最常用的处理方法。

例如股票池里有 5 只股票，涨幅分别是 −5%、−1%、2%、8%、30%，排名后的分数依次是 0、0.25、0.5、0.75、1。那只涨了 30% 的股票仍然排第一，但不会因为数字特别大而影响过头。

公式变长了，可以用**变量**把它拆成两行（`ret20` 是自己起的名字）：

```
ret20 = close / ts_delay(close, 20) - 1
alpha = cs_rank(ret20)
```

#### 第 5 步：决定方向

平台约定：**分数越高，越应该买入**。上面的公式意思是“涨得多的继续买”。如果你的想法相反——“涨多了会跌”（反转），就乘以 `-1` 把分数倒过来：

```
ret5 = close / ts_delay(close, 5) - 1
alpha = -1 * cs_rank(ret5)
```

#### 第 6 步：加入条件

比较运算（如 `pct_chg > 0`）成立时结果是 1，不成立时是 0。配合 `if(条件, 成立时的值, 不成立时的值)` 可以写出“如果…就…”的规则。下面这个因子的意思是：只在上涨的日子里，成交量放得越大分数越低；其他日子一律记 0 分。

```
surge = vol / ts_mean(vol, 20)
alpha = if(pct_chg > 0, -1 * cs_rank(surge), 0)
```

#### 第 7 步：把多个想法合在一起

想同时考虑“涨得多”和“波动小”，先各自排名，再按比例相加。先排名是为了让两个指标处在同一把尺子上：

```
mom = cs_rank(close / ts_delay(close, 60) - 1)
lowvol = -1 * cs_rank(ts_std_dev(pct_chg, 20))
alpha = 0.5 * mom + 0.5 * lowvol
```

#### 写完之后看哪里

- 编辑器底部状态栏显示 **✓ 校验通过**，说明公式写法没有问题，可以运行评价。
- 如果编辑器上方出现一行带 ⚠ 的红字，说明有写错的地方，按“第 N 行”去找。常见报错的改法见页面底部“常见问题”里的**报错信息对照表**。

> [!NOTE]
> 规则小结：每行写一条语句；**最后一行**的结果就是因子的最终分数；变量要先定义、后使用，名字只能用英文字母、数字和下划线，且不能和字段同名；`#` 后面的内容是给人看的备注，不参与计算。
