## 环境与数据

### no-data | 顶栏显示 0 日 × 0 股，或字段数为 0

keywords: tushare token 设置 行情 面板 数据

尚未写入面板。设置 → Tushare Token → 保存。首次拉取受接口限速，可能数分钟。顶栏「N 日 × N 股」非 0 即就绪。

### tushare-token | Token 从哪里获取

keywords: tushare token 积分

tushare.pro 注册后在个人主页复制接口 TOKEN。估值、财务等接口对积分有要求；不足时对应数据集缺失，用到这些字段的因子标为不可用，其余功能不受影响。

### ai-offline | AI 助手显示模型未配置

keywords: ai 模型 api key deepseek openai

接入任一 OpenAI 兼容接口。设置 → 模型 → 添加：访问地址、模型名、密钥 → 测试通过后保存，立即生效。不配置不影响手写、评价、组合与模拟。

### login-token | 要求输入访问令牌

keywords: 登录 FACTOR_LAB_TOKEN

这是部署时的访问控制，与 Tushare Token、模型密钥无关。值为启动参数 `FACTOR_LAB_TOKEN`。

## 表达式

### editor-error | 编辑器出现带行号的校验错误

keywords: 报错 校验 未知字段 算子 非法字符

停止输入约 0.5 s 后静态检查。「✓ 校验通过」只说明句法合法。按行号定位。对照见本节「报错对照」。

### chinese-name | 变量名与窗口约束

keywords: 变量名 中文 窗口 常数

变量名：`[A-Za-z_][A-Za-z0-9_]*`，且不得与字段重名。窗口必须是 1～512 的整数常量。说明性文字用 `#` 注释。

### file-status | 未保存 / 待保存 / 已保存 / 结果待更新

keywords: 未保存 待保存 已保存 结果待更新 入库

- 未保存：草稿，关闭即丢失。
- 待保存：库中已有记录，本地公式已改未写回。
- 已保存：与库中一致。
- 结果待更新：评价之后又改了公式，旧指标作废。

双击名称改名；名称旁入库图标或评价窗「保存」写入因子库。

## 评价与模拟

### negative-ic | RankIC 为负

keywords: rankic 负数 方向

表示高分随后收益更低。\|RankIC\| 足够时，末行乘 `-1` 即得到正向因子。接近 0 才是无信息。

### good-ic | RankIC 量级

keywords: rankic 阈值

日频噪声占主导，IC 均值很小。A 股日频：\|RankIC\| > 0.03 可继续研究，> 0.05 较强；同时看 ICIR > 0.3、\|t\| > 2。0.2 以上应先查对齐与公式。

### slow | 评价耗时

keywords: 慢 股票池 批量

首次切换股票池要下载成分与行情。评价全部会对每条因子做完整回测。缩短区间可加快试错。

### backtest-vs-live | 评价好是否可交易

keywords: 实盘 过拟合 成本

评价只说明该区间内的历史关系。过拟合、成本、样本外衰减都会造成落差。换区间、换股票池，再用模拟盘观察。结果供研究，不构成投资建议。

### unavailable | 当前数据源不支持

keywords: 不可用 roe pe_ttm 字段

公式引用了面板中不存在的列。悬停标签可看到缺哪些字段。

### paper-real | 模拟盘是否下单

keywords: 模拟 券商

否。虚拟记账，规则含 T+1、涨跌停、停牌、100 股整手。

### paper-pending | 待成交

keywords: 待成交 t+1 同步

最新已加载交易日已选出目标，成交发生在下一交易日开盘，而该日行情尚未下载。重启服务更新行情后点「同步新行情」。

### paper-frozen | 修改因子后模拟盘是否变化

keywords: 冻结

否。创建时冻结表达式与历史成交。新公式需新建模拟盘。
