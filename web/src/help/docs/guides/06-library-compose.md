#### 因子库：所有因子的仓库

「因子库」里既有平台预置的经典因子，也有你自己保存的因子。预置因子是公开研究里常见的写法，适合拿来学习和当作起点。

- **批量评价**：勾选几个因子后点 **评价选中**；一个都不勾则是 **评价全部**。评价完成后，表格里会出现每个因子的 RankIC、ICIR 和超额收益。
- **排序**：点表头的 RankIC、ICIR、超额收益（多头）或更新时间，可以从高到低排序，再点一次反过来。
- **筛选**：用搜索框按名称或公式查找，或用下拉框按分类、来源（内置 / 自建 / AI / 组合）过滤。
- **查看详情**：点因子名称，右侧会滑出详情，包含公式、关键指标和图表，并可以 **复制**、**删除** 或 **编辑**。
- **导入 / 导出**：把整个因子库导出成一个文件用于备份，或导入别人分享的因子文件。

> [!NOTE]
> 新手推荐的第一件事：先点一次 **评价全部**，然后按 RankIC 排序，点开排名靠前的几个因子看看它们的公式是怎么写的。

#### 为什么要做组合

单个因子往往“时灵时不灵”。把几个逻辑不同的因子合在一起打分，一个失灵时另一个可能正好有效，整体表现通常更平稳——和“不把鸡蛋放在一个篮子里”是同一个道理。

#### 搭一个组合的步骤

1. 打开「因子组合」，在中间填写 **组合名称**。
2. 点 **+ 新增因子**，从因子库里挑选并点 **加入**（至少 2 个）。也可以点 **让 AI 推荐**。
3. 检查每个因子的 **方向**：如果某个因子的 IC 是负数，点一下把它切换成“反向”，否则它会拖后腿。
4. 选择权重方式：**等权**（每个因子同样重要）或 **自定义权重**（自己填每个因子的比重，数字越大越重要）。拿不准就用等权。
5. 点 **运行评价** 查看组合的表现，满意后点 **保存**。

表格里每一行的 IC、ICIR、收益率是**该因子自己**最近一次评价的结果，用来帮你挑选；显示“—”表示它还没评价过，可以先回因子库批量评价。

#### 看懂相关性表格

组合的评价结果下方有一张“成分因子相关性”表，数字表示两个因子打出的分数有多像，范围 −1 到 1：

- **大于 0.7（红色）**：两个因子几乎在说同一件事，建议只留一个。例如 20 日动量和 60 日动量。
- **0.4～0.7（橙色）**：有一定重复，可以保留但作用有限。
- **低于 0.4（绿色）**：互补性好，是理想的搭配。

合成时，平台会先把每个因子的分数换算到同一把尺子上（标准化），再按权重相加。想看最终合成出来的完整公式，可以展开结果底部的“合成表达式”。
