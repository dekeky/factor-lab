因子研究要回答的问题只有一句：**当天分数更高的股票，在随后的持有期内是否系统性地获得更高收益？**

本教材按这个顺序往下讲：先把「因子」说清楚，再讲数据怎么排、时间怎么对齐，然后写第一条表达式、读评价报告。语法细节在 [DSL 语法](#syntax)，字段单位在 [基础指标](#fields)。

## 1. 一条可计算的规则

因子不是一篇研报，也不是「感觉这只股票不错」。它是一条对全市场同时生效的规则：每个交易日，对股票池里的每一只股票给出一个实数。

平台约定：**分数越高，越倾向买入。** 如果经济学含义是「越大越差」（短期涨幅、波动、换手），在表达式最后乘 `-1`，把方向拧过来。

下面这条是 20 日动量：过去 20 个交易日涨得多的股票，分数更高。

```
# 过去 20 日收益率
ret20 = close / ts_delay(close, 20) - 1

# 当天截面排队，最低 0、最高 1
alpha = cs_rank(ret20)
```

`close` 是收盘价，`ts_delay(close, 20)` 是 20 个交易日前的收盘价，相除减 1 得到收益率。`cs_rank` 把当天所有股票从低到高排成 0～1，量纲和极端值都被压掉。

## 2. 用一张表看「打分」

假设某日三只股票的 20 日收益是：

| 股票 | 20 日收益 | 因子分数（`cs_rank`） |
| --- | ---: | ---: |
| A | +8% | 1.00 |
| B | +1% | 0.50 |
| C | −4% | 0.00 |

评价引擎接下来做的事：看接下来持有期内，A 是否平均比 C 赚得多。赚得多，因子就有预测力；差不多，这条规则就该丢掉。

## 3. 常见类别

写公式之前，先能用一句话说出机制。搜出来的窗口数字没有机制，换一段行情就翻脸。

| 类别 | 典型构造 | 常说的机制 |
| --- | --- | --- |
| 动量 | 过去 60、120 日收益 | 趋势会延续一段时间 |
| 反转 | 过去 5 日收益再取负 | 短期涨多了会往回修 |
| 价值 | E/P、B/P | 便宜的股票有风险补偿，或定价偏了 |
| 质量 | ROE | 赚钱效率高的公司被持续定价 |
| 波动 / 流动性 | 收益标准差、换手 | 投资者不喜欢难交易、大起大落的票 |
| 量价 | 价量相关、放量 | 微观结构和交易行为 |

同一类别里，换窗口通常还是同一条信息。20 日动量和 60 日动量相关很高，一起放进组合几乎不加新东西。

## 4. 先写假设，再写公式

一条能被证伪的假设长这样：

> 过去 20 个交易日涨幅更高的股票，在未来 1 个交易日的截面收益也更高。

对应公式就是上面的 `ret20` + `cs_rank`。评价之后只有三种结果：方向对、方向反了（末尾乘 `-1`）、没有预测力（换假设）。

不要从「把 `close`、`vol`、`roe` 随机组合」开始。那样样本内总能找到好看的数，样本外用不上。
