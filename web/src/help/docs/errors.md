| 校验信息 | 原因 | 处理 |
| --- | --- | --- |
| `未知的字段或变量 "xxx"` | 标识符不在当前面板字段，也不是已定义变量 | 对照基础指标；变量必须出现在使用之前 |
| `未知算子 "xxx"` | 函数名未注册 | 对照算子速查。常见误写：`ts_avg`、`rank`、`ts_std` |
| `算子 xxx 期望 N 个参数，实际 M 个` | 参数个数与签名不符 | `ts_mean(close)` 应为 `ts_mean(close, 20)` |
| `xxx 第 N 个参数必须是常数（如窗口长度 20）` | 窗口位不是数字字面量 | 不能写变量或 `10+10` |
| `xxx 第 N 个参数必须是 1~512 的整数` | 窗口越界 | 禁止 0、负、小数，上限 512 |
| `变量名 "xxx" 与字段重名，请换名` | 与面板列冲突 | 例如不要写 `close = …` |
| `非法字符 "…"` | 词法不允许的字符 | 全角括号、逗号、分号、等号；标识符不能含中文。引号内乱码常是字节被误读，按行号查全角符号 |
| `期望 xxx，实际是 xxx ／ 意外的记号` | 句法不完整 | 括号配对、运算符缺失、尾逗号 |
| `空表达式：至少需要一行因子定义` | 没有有效语句 | 仅注释或空行不算 |
| `表达式嵌套过深` | 括号层数 > 64 | 拆成中间变量 |
