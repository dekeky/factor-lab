第一次接触量化也没关系。这个平台只做一件事：**帮你检验一条选股规则到底靠不靠谱**。你把规则写成一小段公式（叫“因子”），平台用历史行情告诉你：按这条规则挑出来的股票，后来是不是真的涨得更好。

1. **因子 · 一条打分规则** — 每天给每只股票打一个分，例如“过去 20 天涨了多少”。
2. **评价 · 用历史来检验** — 回看过去的每一天：分数高的股票，之后是不是真的涨得更多？
3. **模拟盘 · 用虚拟资金试跑** — 规则通过检验后，用虚拟资金每天买入分数最高的股票，观察账户怎么变化。

### 5 步跑通第一个因子

1. **准备行情数据**（{{data_status}}）  
   点左下角的「设置」，填入 Tushare Token 并保存（Token 是什么、在哪里拿，见页面底部[常见问题](#faq)）。页面右上角的“面板 N 日 × N 股”不再是 0，就说明数据已经就绪。
2. **打开因子工厂，准备一段公式**  
   点左侧导航的「[因子工厂](#/factory)」。编辑器里已经有一段示例公式，可以直接用；也可以复制下面这段粘贴进去。
3. **运行评价**  
   点编辑器右上角的「▶ 运行评价」（或按 Ctrl+Enter）。弹出的参数窗口第一次全部保持默认，直接点「▶ 开始评价」，稍等片刻。
4. **看结果**  
   先只看三处：① **RankIC 均值**，绝对值大于 0.03 说明有预测能力（负数只代表方向反了）；② **多头累计超额**，正数说明高分股票跑赢了平均水平；③「分层回测」柱状图，从左到右逐级升高最理想。[详细解读](#guide-read-report)
5. **起名并保存**  
   关闭结果窗口，在左侧列表里双击“未命名”改一个好记的名字，再点名称右边的入库小图标。之后就能在「因子库」里找到它。

```momentum.factor
# 20 日动量：每行一条语句
ret20 = close / ts_delay(close, 20) - 1
alpha = cs_rank(ret20)
```

| 行 | 代码 | 含义 |
| --- | --- | --- |
| 第 1 行 | `# 20 日动量：每行一条语句` | 以 `#` 开头的是备注，写给人看的，平台计算时会忽略它。 |
| 第 2 行 | `ret20 = close / ts_delay(close, 20) - 1` | 今天的收盘价 ÷ 20 个交易日前的收盘价 − 1，得到这 20 天的涨幅。结果存进一个自己起名的变量 `ret20`。 |
| 第 3 行 | `alpha = cs_rank(ret20)` | 把当天所有股票按涨幅从低到高排名，换算成 0～1 的分数。最后一行的结果就是因子的最终分数：分数越高，越应该买入。 |

### 四个页面分别做什么

- [**因子工厂**](#/factory) — 写公式、做评价的工作台。左边是你的因子列表，中间是公式编辑器，右边是 AI 助手。写好公式后点「▶ 运行评价」就能看到结果。
- [**因子库**](#/library) — 所有因子的仓库。预置了一批经典因子，也存放你自己保存的因子。可以批量评价、按指标排序，快速找出表现好的。
- [**因子组合**](#/compose) — 把几个因子合成一个。多个因子一起打分通常比单个因子更稳。这里还会检查因子之间是否太相似。
- [**实盘模拟**](#/paper) — 用虚拟资金试跑。按因子每天选股、买卖，查看持仓和账户净值曲线。全程虚拟记账，不会产生真实交易。
