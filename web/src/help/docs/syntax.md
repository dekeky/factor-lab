DSL 是平台用来写因子的公式语言，写法和 Excel 公式很像。这一节是完整的规则说明；刚入门可以先读教程[从零写出第一个因子](#guide-first-factor)，用到时再回来查。

一个因子由一条或多条语句组成。变量按顺序定义，{{dsl.result}}。

| 类别 | 规则 |
| --- | --- |
| 语句 | 赋值 `name = expression`，或直接写一个表达式。 |
| 分隔 | {{dsl.separators}}；空行会被忽略。 |
| 注释 | `{{dsl.comment}}`，适合记录想法和假设，不参与计算。 |
| 数值 | 支持整数、小数与科学计数法，如 `20`、`0.001`、`1e-3`。 |
| 变量 | 只能用英文字母、数字和下划线，不能以数字开头；必须先定义后使用，且不能与字段重名。 |
| 限制 | 窗口为 1~{{dsl.max_window}} 的整数，必须直接写数字；表达式最多嵌套 {{dsl.max_depth}} 层。 |

### 运算符与优先级

和数学里“先乘除、后加减”一样，排在前面的先算；拿不准时加括号最保险。从高到低：{{dsl.precedence}}

| 类别 | 写法 | 结果 | 例子 |
| --- | --- | --- | --- |
| 算术 | `+  -  *  /  -x` | 对每只股票每一天分别计算；除数为 0 时结果为缺失值 | `(close - open) / open` |
| 比较 | `<  <=  >  >=  ==  !=` | 成立为 1，不成立为 0；有缺失值参与时按不成立处理 | `pct_chg > 0` |
| 逻辑 | `not x  x and y  x or y` | “非 / 并且 / 或者”；非 0 且非缺失视为成立 | `pct_chg > 0 and vol > ts_mean(vol, 20)` |

缺失值（NaN）表示“这里没有数据”。加减乘除遇到缺失值，结果通常也是缺失值；滚动求和、求均值会跳过窗口内的缺失值；具体行为见各算子说明。
