有了定义和对齐，就可以按固定顺序做一次实验。不要在窗口数字上打转：先淘汰，再对留下的少数加深。

## 1. 六步

| 步骤 | 做什么 | 页面 |
| --- | --- | --- |
| 1. 假设 | 用一句话写下可证伪的命题 | — |
| 2. 表达式 | 译成 DSL，先单层再嵌套 | [因子工厂](#/factory) |
| 3. 评价 | 看 RankIC、分层、多头净收益 | 因子工厂 → 运行评价 |
| 4. 稳健性 | 换区间、持有期或股票池，结论应同向 | 评价参数 |
| 5. 组合 | 逻辑不同的因子合成，检查相关 | [因子组合](#/compose) |
| 6. 模拟 | 按 T+1、涨跌停、整手规则记账 | [实盘模拟](#/paper) |

常见节奏：并行写 5～10 个变体 → 用评价淘汰 → 只对留下的少数做第 4～6 步。多数假设会被证伪，这是正常产出，不是失败。

## 2. 十分钟上手

1. 设置中填写 Tushare Token，等顶栏出现「N 日 × N 股」（不是 0×0）。首次拉数受接口限速，可能要几分钟。
2. 打开[因子工厂](#/factory)，把下面这段贴进编辑器（或直接用编辑器里的示例）：

```
# 20 日动量：涨得多的，分数高
ret20 = close / ts_delay(close, 20) - 1
alpha = cs_rank(ret20)
```

3. 停大约半秒，状态栏应出现「✓ 校验通过」。这只说明句法和算子签名合法，不说明因子有效。
4. 评价参数先保持默认（持有期 1、10 组、单边成本 0.003），点运行评价。
5. 报告出来后先看三件事（下一章细讲）：
   - RankIC 均值的**绝对值**
   - 分层收益是否大致从低分到高分递增
   - 多头(净) 是否高于全市场等权
6. 起个能看懂的名字，入库。

## 3. 怎么把假设译成公式

把那句话拆成「对每只股票算什么」和「当天怎么比」。

| 假设 | 对每只股票 | 当天怎么比 |
| --- | --- | --- |
| 涨得多的接下来还涨 | `close / ts_delay(close, 20) - 1` | `cs_rank(...)` |
| 波动大的接下来收益差 | `ts_std_dev(pct_chg, 20)` | `-1 * cs_rank(...)` |
| ROE 高的更好 | `roe` | `cs_rank(roe)` |

写作顺序：先跑通内层（例如只有 `ts_mean(close, 20)`），再包 `cs_rank`，最后加符号或加权。复杂式拆成中间变量，最后一行才是因子值。

```
mom = cs_rank(close / ts_delay(close, 60) - 1)
lowvol = -1 * cs_rank(ts_std_dev(pct_chg, 20))
alpha = 0.5 * mom + 0.5 * lowvol
```

加权前各自 `cs_rank`，不要把收益率和成交量直接相加。

## 4. 样本内和样本外

研究时盯过、调过参数的区间是样本内。换一段**从没用来调参**的区间再评价一次，才叫样本外。

- 窗口优先用 5 / 20 / 60 / 120 / 250，不要在 17、23 上搜索。
- 参数稍改、结论就反号的因子，丢掉。
- 评价好看不等于可交易。过拟合、费用、样本外衰减都会造成落差。换区间、换股票池，再用模拟盘看一眼。
