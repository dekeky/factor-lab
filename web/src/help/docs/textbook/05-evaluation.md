评价引擎是冻结的裁判：同一条公式、同一段面板，谁来跑数字都一样。这一章对照因子工厂顶部的卡片和四张图。收益对齐见[时间对齐](#guide-alignment)，公式不再重复推导。

## 1. 每个交易日引擎在算什么

对每个信号日 `t`：

1. 用 `t` 及以前的数据得到因子值。
2. 前向收益 `fwd_ret(t) = close(t+1+H) / close(t+1) - 1`。
3. 在当日**因子和收益都有值**的股票上算 IC、RankIC，并按因子分位分成 G 组（默认 10 组）。
4. 有效股票数低于 `MinStocks`（默认 5）时，这一天跳过，不进 IC 均值。

图里红为正、绿为负，跟 A 股习惯一致。

## 2. IC 和 RankIC

IC 是当天因子值与前向收益的 Pearson 相关，范围 [−1, 1]。

| 取值 | 含义 |
| --- | --- |
| 接近 1 | 高分随后涨得多 |
| 接近 0 | 没有线性预测力 |
| 接近 −1 | 方向反了，不是「没信息」 |

日频真实 IC 很小。噪声占主导，均值到 0.03～0.05 已经值得继续；突然出现 0.2 以上，先怀疑公式或时间对齐写错。

**RankIC** 先把因子和收益都换成名次再做相关，对极端收益不敏感。平台以 RankIC 为主要指标。

## 3. 顶部卡片

| 卡片 | 问的问题 | 日频经验起点（不是标准） |
| --- | --- | --- |
| RankIC 均值 | 有没有预测力 | \|RankIC\| > 0.03 可继续；> 0.05 较强。负号只表示方向 |
| RankICIR | 预测力是否稳定 | ICIR = 均值 / 标准差。> 0.3 较稳，> 0.5 强 |
| t 值 | 均值是不是像噪音 | `t = 均值 / (标准差 / √n)`。\|t\| > 2 通常拒绝「均值其实是 0」 |
| 多头累计超额 | 最高组相对全市场等权多赚多少 | 应为正。这是毛收益，还要对照年化成本 |
| P(IC>0.02) | IC 大于 0.02 的天数占比 | 用的是 Pearson IC，不是 RankIC |
| 覆盖度 | 能算出因子值的股票比例 | 全样本非 NaN 比例。过低则结论不可靠 |

阈值随股票池、持有期、区间变化，只作起点。截面上因子值全相同或收益全相同时，相关系数无定义，该日不进 IC 均值，但分层净值仍会推进。

## 4. 四张图

每日按因子**升序**分成 G 组：Q1 最低，Q10 最高（10 组时）。

| 页签 | 内容 | 比较理想的形态 |
| --- | --- | --- |
| 分层回测 | 各组单期均收益与累计收益 | Q1 → Q10 近似单调 |
| 分层净值 | 各组净值，起点 1 | Q10 在上、Q1 在下，少交叉 |
| IC 时序 | 逐日 IC / RankIC | 同号时间长，而不是围着 0 频繁翻面 |
| 多头 vs 全市场 | 多头(毛)、多头(净)、全市场等权 | 净曲线长期在全市场之上 |

多空（Q10−Q1）只作研究参考。A 股融券约束下，以多头结论为主。

## 5. 换手和成本

换手 = 最高分组相对上一期的成员更换比例。年化成本粗估：

```
年化成本 ≈ 日均换手 × 2 × 单边成本 × 252
```

默认单边成本 `0.003`（0.3%）。日换手 20% 时：

```
0.20 × 2 × 0.003 × 252 ≈ 30%
```

短周期反转 IC 往往好看，换手也高，扣费后多头经常输给全市场。多头(净) 已经按「当日换手 × 双边成本」从净值里扣过。

## 6. 三步判断，不要只看一张卡片

1. **预测力**：\|RankIC\| 和 \|t\| 是否过线。
2. **结构**：分层是否大致单调。两头高、中间低，不是「越高越好」。
3. **成本后**：多头(净) 是否仍高于全市场。

任一步明显失败，改表达式或放弃，而不是继续搜窗口。

## 7. 常见形态

| 现象 | 含义 | 动作 |
| --- | --- | --- |
| RankIC < 0，柱子递减 | 方向反了 | 最后一行乘 `-1` |
| RankIC ≈ 0，柱子乱 | 无预测力 | 换假设 |
| 两头高、中间低 | 非线性 | 用 `abs` 或 `if` 重写 |
| RankIC 尚可，净收益差 | 换手吃费用 | `ts_mean` / `ts_decay_linear` 平滑，或加大 H |
| 覆盖度低 | 缺字段或窗口过长 | 查 [基础指标](#fields) |
| 前半段好、后半段差 | 衰减或样本内巧合 | 分段再评价，谨慎使用 |
