公式里的 `close`、`vol`、`roe` 看起来像一个数，引擎里每一列都是一张二维表：行是交易日，列是股票。算子决定沿哪一个方向算。

## 1. 面板长什么样

以 `close` 为例：

|  | 股票 A | 股票 B | 股票 C |
| --- | ---: | ---: | ---: |
| 日 t−2 | 10.0 | 50.0 | 8.0 |
| 日 t−1 | 10.5 | 49.0 | 8.0 |
| 日 t | 11.0 | 49.5 | 7.6 |

`close` 在「日 t、股票 A」这个格子上是 11.0。`pct_chg`、`vol`、`roe` 各自是同样形状的一张表，格子里的数含义不同。

当前面板有哪些列、单位是什么，以 [基础指标](#fields) 为准。Tushare 源默认日 K + 每日指标 + ROE；CSV 源有什么表头就能引用什么。

## 2. 两个方向：TS 和 CS

| 前缀 | 怎么分组 | 问的问题 | 例子 |
| --- | --- | --- | --- |
| `ts_*` | 固定一只股票，沿时间往回看 | 相对它自己的过去如何 | `ts_mean(close, 20)`：这只股票最近 20 日均价 |
| `cs_*` | 固定一个交易日，横着比所有股票 | 同一天谁高谁低 | `cs_rank(roe)`：当天 ROE 分位，0～1 |
| 数学 / `if` | 每个格子单独算 | 不引入窗口 | `log(total_mv)`、`if(pct_chg > 0, vol, 0)` |

经验规则：

- 句子里有「过去 d 天」→ 用 TS
- 句子里有「当天谁更强」→ 用 CS
- 只是取对数、取绝对值、做分支 → 用数学或 `if`

窗口按**交易日行**推进，不是自然日。停牌如果仍占一行，会计入窗口。

## 3. 用手算一遍

还用上面那张 `close` 表。看股票 A 在日 t 的两个量：

```
# 相对自己：3 日均价（A 在 t 日）
# (10.0 + 10.5 + 11.0) / 3 = 10.5
ts_mean(close, 3)

# 相对当天别人：收盘价截面分位
# t 日三只股票收盘 11.0、49.5、7.6 → A 排中间 → 0.5
cs_rank(close)
```

`ts_mean` 不会拿 A 和 B 比；`cs_rank` 不会拿 A 昨天的价格来比。嵌套时按从内到外算：

```
# 先各自做 20 日均价，再在当天排队
cs_rank(ts_mean(close, 20))
```

先写反（时序包截面）语义会变，结果也难解释。例如 `ts_mean(cs_rank(close), 20)` 是「每天先排名，再对排名做 20 日均值」，和「先均价再排名」不是同一个因子。

## 4. 窗口从哪一天开始有值

`ts_mean(close, 20)` 在每只股票的前 19 行是缺失值（NaN），这叫 warmup：窗口还没填满。不是报错。评价、覆盖度都会把这些格子跳过。

窗口必须是字面整数，范围 1～512。不能写变量，也不能写 `10+10`。常用且有市场含义的窗口：

| 窗口 | 大约对应 |
| --- | --- |
| 5 | 一周 |
| 20 | 一个月 |
| 60 | 一个季度 |
| 120 | 半年 |
| 250 | 一年 |

完整算子签名见 [算子速查](#operators)。
